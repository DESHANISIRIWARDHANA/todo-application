## Project Description

A simple, responsive todo list web app: add, complete and delete tasks, filter
by status, and keep everything in the browser via `localStorage`.

## Branch Strategy

- `main` — production, protected, auto-deployed
- `develop` — integration branch
- `feature/*` — one branch per task
